# 幕间 · 音乐剧排期

[点击体验幕间](https://yjshen126.github.io/MusicalFinder/)

幕间是一个音乐剧排期查询与观剧记录工具，帮助观众从发现演出、挑选场次，到收藏心仪内容、记录观剧体验，更轻松地安排每一次走进剧场。

## 定位

音乐剧的演出信息往往分散在剧院、剧目和演员的不同渠道中。想找一场时间合适、地点方便、卡司心仪的演出，常常需要反复搜索和对照；看过的演出也容易散落在票根、相册和备忘录里。

幕间希望把这些零散的步骤串联起来，让查询排期和记录观剧成为一件简单、连贯的事。

## 特色

- **多维度查找排期**：按城市和日期浏览演出，也可以搜索剧名、演员或剧院，快速找到感兴趣的场次。
- **按卡司组合筛选**：从角色和演员出发筛选场次，帮助观众找到心仪演员同台的演出。
- **建立个人想看清单**：收藏单场演出、剧目、演员或剧院，方便之后集中查看。
- **记录每一次观剧**：在观剧日历中保存场次、票价、评分和感受，回顾每月及年度的观剧足迹。
